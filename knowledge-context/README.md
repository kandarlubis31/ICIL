# 🗃️ Faculty of Knowledge & Context Engineering — Overview

> **10 Courses** | Beginner → Advanced | Domain: Knowledge architecture, context design, document engineering, routing, provenance, evaluation, security, and agent integration

The **knowledge layer** for AI systems. This faculty teaches how to turn a growing body of documents into reliable, scoped, maintainable context for agents. It sits between raw content and agent execution: `ia/` focuses on organizing information for people and systems, `ai-integration/` focuses on building LLM applications, and `agentic-engineering/` focuses on running autonomous agents in production. This faculty focuses on the operational discipline of the context itself.
