# 📝 06 — Campus & Youth Slang

> 🟢 Beginner | Prereq: 01 | ~10 min

Indonesian university campuses are slang factories. Every faculty, cohort, and student organization generates its own compressed vocabulary for surviving academic life — from cramming systems to senior-junior dynamics. This course maps the campus lexicon and teaches you to write authentic student voices.

---

## 6.1 The Campus Lexicon

### Academic Survival

| Term | Expansion | Meaning |
|------|-----------|---------|
| **SKS** | Sistem Kebut Semalam | Cramming everything the night before deadline |
| **Dospem** | Dosen Pembimbing | Thesis supervisor |
| **Sempro** | Seminar Proposal | Thesis proposal defense |
| **Semhas** | Seminar Hasil | Thesis results seminar |
| **Kompre** | Komprehensif | Comprehensive exam |
| **IPK** | Indeks Prestasi Kumulatif | GPA |

### People & Roles

| Term | Expansion | Meaning |
|------|-----------|---------|
| **Kating** | Kakak Tingkat | Senior student |
| **Maba** | Mahasiswa Baru | Freshman |
| **Almet** | Almamater | University jacket (status symbol) |
| **Coki-coki** | (standalone) | Freeloader group member |
| **Bemawa** | Biro Kemahasiswaan | Student affairs bureau |

### Social Life

| Term | Meaning | Context |
|------|---------|---------|
| **Nongkrong** | Hanging out (hours-long) | Essential campus social ritual |
| **Katingan** | Kating + Kantin | Senior hanging at canteen |
| **Titip Absen / Tipemen** | Proxy attendance signing | Skipping class |
| **Organisator** | Student org activist | Contrasts with *anak akademik* |
| **Nugas** | Doing assignments | Default student activity |

## 6.2 The Campus Slang Formation Pattern

```
Long Formal Terms       →     Compressed Slang
─────────────────────────────────────────────
Kakak Tingkat           →     Kating
Mahasiswa Baru          →     Maba
Dosen Pembimbing        →     Dospem
Seminar Proposal        →     Sempro
Sistem Kebut Semalam    →     SKS (redefined)
```

The pattern is always: **compress → pronounceable → 2-3 syllables.**

## 6.3 Writing Campus Dialogue

### Undergraduate Voice

```
"Maba jangan terlalu keliatan ya, nanti di-kerjain kating."
"Coki-coki mulu sih, nugas dikit kek!"
"Sempro besok, SKS mode activated."
```

### Graduate/Professional Voice

```
"Dospem gue minta revisi bab 4, padahal udah semhas."
"Kompre tahun ini katanya lebih susah."
```

### Cross-Campus Variations

| Campus Type | Slang Characteristic |
|-------------|---------------------|
| **PTN (Public)** | More Indonesian, more formal-leaning slang |
| **PTS Elite (Private)** | Heavier Jaksel code-switching |
| **Kedinasan (Service academies)** | Military/formal register, minimal slang |
| **Vokasi (Vocational)** | Industry-specific jargon mixed in |

## 6.4 Generational Shift: Gen Z → Gen Alpha

| Old Term (Millennial) | New Term (Gen Z/Alpha) | Note |
|----------------------|----------------------|------|
| *Gue / Lo* | Still standard | No replacement yet |
| *Alay* | *Skena* (for hipsters) | Alay now almost ironic |
| *Galau* | *Overthinking* | Shift toward English |
| *Curhat* | *Spill the tea / Spill* | English borrowing |
