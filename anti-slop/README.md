# 🚫 Faculty of Anti-Slop & Authentic Output — Overview

> **7 Courses** | Level: Beginner → Advanced | Domain: AI Slop Detection, Editorial Quality & Authentic Voice

"Slop" — mass-produced, uncured, generic AI output — was Merriam-Webster's Word of the Year 2025 for a reason: generation is cheap, curation is not. This faculty gives agents the vocabulary, catalogs, and workflows to detect and remove slop across all three domains it appears in: **prose** (clichés, triads, hedging), **code** (narrating comments, dead abstractions), and **UI** (generic generated dashboards with dead flows). It ends with building authentic voice systems instead of merely clean ones.

## 🎯 Learning Paths

### Beginner Path (Recognize the Waste)
```
01
```
Definition, causes (median-token generation, RLHF agreeableness, no curation loop), and the slop-vs-generic judgment tests.

### Intermediate Path (Filter, Then Restructure)
```
01 → 02 → 03 → 05
```
Banned lexicon for text across English and Indonesian, structural tells, and the generated-UI pattern catalog.

### Advanced Path (Ship Filters and Voice)
```
01 → 02 → 03 → 06 → 07
```
Packaging the catalogs into skill documents with trap-prompt testing, then building layered voice systems with drift review.
