# audit — Project Context

## Ringkasan
Research-backed audit protocol for the 30-faculty, 226-course catalog. This directory separates editorial/content review from the release and CI checklist in AUDIT-PLAN.md . The audit is intentionally evidence-based: automated scans identify candidates, while research review decides whether a course is accurate, current, well-scoped, and useful for context injection.
